如何添加（不要导入）

  • Google Calendar 网页端：左侧「其他日历」→「+」→「通过网址」→ 粘贴 ICS 链接。
  • iPhone/iPad：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历。
  • macOS：日历 App → 文件 → 新建日历订阅 → 粘贴 ICS 链接。
